# ⚡ React + Vite + TypeScript

A modern web app starter using **React**, **Vite**, and **TypeScript** — offering lightning-fast development, hot module replacement, and support for clean builds and production deployment via GitHub Pages.

---

## 🚀 Features

- ⚛️ React with JSX and Hooks
- ⚡ Vite for blazing-fast development and builds
- 🧪 TypeScript for static typing
- 🔄 Hot Module Replacement (HMR)
- 🧹 Pre-configured ESLint (with basic rules)
- 🌐 GitHub Pages deployment-ready

---

## 📦 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/Ni-Kit-Mht/portfolio-react.git
cd portfolio-react

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
